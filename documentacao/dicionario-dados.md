# Dicionário de Dados

## Tabela: Vendas

| Coluna | Descrição |
|----------|----------|
| Produto | Produto adquirido pelo cliente |
| Preço | Valor original do produto |
| Pgto. | Forma de pagamento utilizada |
| Nº Parcelas | Quantidade de parcelas da compra |
| Data | Data da venda |
| Cliente | Nome do cliente |
| E-mail | E-mail do cliente |
| DDD | Código de área telefônica |
| Telefone | Número de telefone do cliente |
| Produto-Valor | Coluna criada no Power Query para identificar o produto e o valor pago na mesma célula (Ex.: A-500) |

---

## Tabela: Localização

| Coluna | Descrição |
|----------|----------|
| Prefixo | Prefixo telefônico utilizado para associação geográfica |
| Estado | Estado do cliente |
| Região | Região do Brasil correspondente ao estado |
