# Modelagem dos Dados

## Tabelas Utilizadas

### Vendas

Tabela principal contendo informações das vendas realizadas.

### Localização

Tabela auxiliar contendo informações geográficas associadas aos clientes.

## Relacionamento

O relacionamento foi realizado utilizando o campo de prefixo telefônico, permitindo associar cada cliente ao respectivo estado e região.

## Objetivo da Modelagem

Permitir análises integradas de:

- Faturamento
- Quantidade de vendas
- Forma de pagamento
- Parcelamento
- Distribuição geográfica dos clientes
